Opis:

Učenik u Tehničkoj školi Daruvar. Volim programiranje i dizajn web stranica. U slobodno vrijeme volim raditi na projektima kojima razvijam svoje vještine.

Edukacija:

Trenutni edukacijski status: Učenik
Udemy tečaj: The Complete Full-Stack Web Development Bootcamp

Radne vještine:

Programiranje (HTML, CSS), dizajn web stranica, uvod u programski jezik C i C++, osnovno znanje o SQL i izradi baza podataka.

Nagrade i priznanja:

  • SoloLearn (certifikat) za uspješan završetak tečaja programskog jezika C.
  • Završetak prvog stupnja tečaja C#.
  • Završetak ljetnog gaming kampa Blender, Unity.

Što želim postići:

  • Želim postići bolje razumijevanje i znanje o izradi Web stranica (HTML, CSS, JavaScript).
  • Naučiti Python, SQL, dizajn web stranica.
  • Rukovati s video editiranjem, VFX pomoću Blendera. Poboljšati znanje o GitHubu.
